# 나갈토끼 PWA (홈 화면 설치형 웹앱)

이 폴더를 인터넷에 올리면 링크 하나로 안드로이드·아이폰 모두 "홈 화면에 추가"로 앱처럼 설치돼요. 스토어 심사·설치 파일 없음, 무료.

## 올리는 법 (GitHub Pages, 무료, 10분)
1. github.com 로그인 → New repository → 이름 `nagal-tokki`, Public → Create
2. "uploading an existing file" 클릭 → 이 폴더 안 파일 전부 끌어다 놓기 → Commit
3. 저장소 Settings → Pages → Branch: main, / (root) → Save
4. 1~2분 뒤 `https://<내아이디>.github.io/nagal-tokki/` 가 주소예요. 이 링크를 시범 이용자에게 보내요.

## 이용자 안내
- 안드로이드(크롬): ⋮ → "홈 화면에 추가" / "앱 설치"
- 아이폰(사파리): 공유 버튼 → "홈 화면에 추가"
- 앱 안 설정에도 같은 안내가 있어요. 두 번째 방문부터 위쪽에 안내 띠가 떠요.

## 기록
- 체크·당근·꾸미기 기록은 각자 폰 안(브라우저 저장소)에만 있어요. 서버 없음.
- 같은 폰에서 사파리/크롬 다르게 열면 기록이 따로예요. 홈 화면 아이콘으로만 열도록 안내하세요.
- 폰 저장소를 지우면 기록이 사라져요. 시범 기간에는 괜찮고, 정식 때 "기록 내보내기"를 넣으면 돼요.

## 다음 단계 (APK가 꼭 필요해지면)
pwabuilder.com 에 위 주소를 넣으면 안드로이드 APK/AAB를 무료로 만들어 줘요. GitHub Actions보다 쉬워요.

## 파일
- index.html 앱 본체 (기존 웹 시안 + 설치 안내 + 오프라인 캐시)
- manifest.json 앱 이름·아이콘·색
- sw.js 오프라인 캐시 (앱 파일만)
- icon-*.png, apple-touch-icon.png 아이콘 (임시. 나중에 그림 AI로 그린 토끼로 교체)
